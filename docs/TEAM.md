## คำถามที่น่าจะโดนถาม (เตรียมคำตอบ)
- **ทำไมไม่ใช้ CNN บนภาพปกติ:** เราใช้ HexConvGRU บนตาข่ายเดียวกันเป็น baseline (M4, M5) ทุกโมเดลจึงเห็น input เดียวกัน
- **โมเดล connectome มีพารามิเตอร์น้อยแบบนี้จะเรียนรู้ได้อย่างไร:** โครงสร้างถูกกำหนดไว้แล้ว เหลือให้ปรับแค่ "ค่าความแรง" ซึ่งเป็นคำถามหลักของงานนี้พอดี
- **ทำไมแบ่งข้อมูลตามฉาก ไม่สุ่มรายเฟรม:** เฟรมติดกันแทบเหมือนกัน ถ้าสุ่มรายเฟรม test จะง่ายเกินจริง (data leakage)
- **ถ้าผลออกมาว่า connectome ไม่ช่วย:** เป็นผลที่มีค่า เราลงทะเบียนสมมติฐานไว้ล่วงหน้าและรายงานตามจริง
