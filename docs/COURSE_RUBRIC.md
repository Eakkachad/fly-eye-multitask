## 1. ความยากของงาน (4 คะแนน)
เลือกประเภทงานที่ทำได้คะแนนสูงสุดเพียง**ประเภทเดียว** ไม่นำคะแนนข้ามประเภทมารวมกัน

| ประเภทงาน | คะแนน | ลักษณะงาน |
|---|---|---|
| **Multi-task Learning หรือ Video Analysis** | **4** | แบบจำลองเรียนรู้ร่วมกันตั้งแต่ 2 งานขึ้นไป หรือวิเคราะห์วิดีโอโดยใช้ความสัมพันธ์ระหว่างเฟรม |
| Image Segmentation หรือ Pixel Regression | 3 | จำแนกประเภทระดับพิกเซล หรือทำนายค่าต่อเนื่องระดับพิกเซล เช่น แผนที่ความลึก |
| Object Detection หรือ Image Regression | 2 | ตรวจจับตำแหน่งและประเภทวัตถุ หรือทำนายค่าตัวเลขระดับภาพ |
| Multilabel Image Classification | 1.5 | หลายป้ายกำกับต่อภาพ |
| Multiclass Image Classification | 1 | หนึ่งคลาสจากหลายคลาส |

**เงื่อนไข**
- ต้องมีแบบจำลองที่ทำงานได้จริง และมีผลประเมินที่สอดคล้องกับประเภทงานที่เลือก การเขียนประเภทงานไว้ใน proposal อย่างเดียวไม่นับ
- **Multi-task:** ต้องมีอย่างน้อย 2 งานที่เรียนรู้ร่วมกันในแบบจำลองเดียว และรายงานผลแยกแต่ละงาน การเปรียบเทียบหลายแบบจำลองในงานเดียวไม่นับเป็น multi-task
- **Video Analysis:** ต้องใช้ข้อมูลเชิงเวลาหรือความสัมพันธ์ระหว่างเฟรม ถ้าแยกวิดีโอเป็นภาพแล้วทำนายทีละเฟรมโดยอิสระ จะไม่ได้ 4 คะแนน
- ถ้าไม่มีแบบจำลองหรือผลประเมินที่ตรวจสอบได้ ส่วนนี้ได้ **0 คะแนน**

## ตัวอย่างตัวชี้วัดที่เหมาะสม
| ประเภทงาน | ตัวชี้วัด |
|---|---|
| Image Classification | Precision, Recall, F1, Confusion Matrix (Accuracy ใช้ประกอบได้) |
| Object Detection | mAP, Precision, Recall (ระบุเกณฑ์ IoU) |
| Image Segmentation | Dice หรือ IoU พร้อมภาพเทียบ ground truth |
| Image Regression | MAE หรือ RMSE พร้อมหน่วย |
| Video Analysis | เลือกให้สอดคล้องกับงาน |
