# ความรู้พื้นฐาน (สำหรับสมาชิกในกลุ่ม)

## Connectome คืออะไร
- **Connectome** คือแผนที่ว่าเซลล์ประสาทแต่ละตัวในสมองเชื่อมต่อกับตัวไหนบ้าง (wiring diagram) ได้มาจากการถ่ายภาพด้วยกล้องจุลทรรศน์อิเล็กตรอนแล้วไล่เส้นใยประสาททีละเส้น
- **FlyWire (Nature, 2024)** ทำ connectome ของสมองแมลงหวี่ตัวเต็มวัยได้ทั้งสมอง มีเซลล์ประสาทราว 139,000 ตัว และ synapse หลายสิบล้านจุด
- **ความหมายเชิง deep learning:** connectome คือ "สถาปัตยกรรม" ที่วิวัฒนาการออกแบบมาให้ ไม่ต้องเรียนรู้จากข้อมูล

## flyvis คืออะไร
- **ที่มา:** Lappalainen et al. (Nature, 2024) นำ connectome ของ**ระบบการมองเห็น** (optic lobe) มาสร้างเป็น neural network ใน PyTorch
  - wiring ทั้งหมดมาจากข้อมูลจริง
  - ให้ train เฉพาะพารามิเตอร์เล็ก ๆ ไม่กี่ร้อยตัว ได้แก่ ค่าคงที่เวลาของเซลล์ และความแรงของการเชื่อมต่อ
- **ผลในเปเปอร์:** หลัง train ให้ทำนาย optic flow โมเดลสามารถทำนายการตอบสนองของเซลล์จริงในแมลงหวี่ได้ (เช่น เซลล์ T4/T5 ที่ตรวจจับทิศการเคลื่อนไหว) ทั้งที่ไม่เคยได้ข้อมูลการวัดสมองจริงเลย
- **บทบาทในโปรเจกต์นี้:** flyvis คือ M1 ส่วน M2/M3 คือ flyvis ที่ทำลายรูปแบบ wiring ไป

## Null model คืออะไร (หัวใจของการทดลอง)
- ถ้าโมเดลที่ใช้ connectome ทำงานได้ดี ยังสรุปไม่ได้ทันทีว่าเป็นเพราะ "wiring จริง" อาจเป็นเพราะคุณสมบัติทั่วไปอื่น เช่น ความ sparse หรือจำนวนการเชื่อมต่อต่อเซลล์ก็ได้
- **Null model** คือกราฟปลอมที่เก็บคุณสมบัติทั่วไปเหล่านั้นไว้ แต่ทำลายรูปแบบเฉพาะทิ้ง
- **วิธีอ่านผล:**
  - M1 ชนะ M2 แปลว่ารูปแบบเฉพาะของ connectome มีประโยชน์จริง
  - M1 เสมอ M2 แปลว่าประโยชน์มาจากคุณสมบัติทั่วไป ข้อนี้ก็เป็นผลที่มีคุณค่า

## งานวิจัยต่อเนื่องของกลุ่ม (ที่มาของโปรเจกต์)
ก่อนโปรเจกต์นี้ เรามีงานวิจัยแยกชื่อ **kagpt-fly** (เขียนด้วย Rust + CUDA) ศึกษาสมองแมลงหวี่ทั้งสมอง (โมเดล LIF ของ Shiu et al., Nature 2024) ด้วยคำถามว่า "ต้องใช้ข้อมูล wiring กี่บิตสมองจึงยังทำงานได้" ผลที่เกี่ยวข้องกับโปรเจกต์นี้:
- **สถิติระดับกราฟไม่พอ:** สมองที่สลับสายแบบเก็บ degree ไว้ **เสียพฤติกรรมทั้งหมด** แต่ถ้าเก็บโครงสร้าง "ชนิดเซลล์ต่อชนิดเซลล์" ไว้ จะกู้พฤติกรรมคืนได้ส่วนใหญ่
- **ข้อมูลที่จำเป็นขึ้นกับงาน:** แต่ละพฤติกรรมพึ่ง wiring ละเอียดของบริเวณสมองคนละส่วน
- **วิธีวิจัย:** ลงทะเบียนสมมติฐานก่อนทดลอง ใช้ null control และใช้ seed ใหม่ตอนยืนยันผล โปรเจกต์นี้ใช้วิธีเดียวกัน

**โปรเจกต์นี้ต่อยอดคำถามเดียวกันมาสู่ deep learning ของภาพ:** "โครงสร้างจากชีววิทยาช่วยแทนพารามิเตอร์และข้อมูลได้แค่ไหน"

## คำศัพท์
| คำ | ความหมาย |
|---|---|
| Optic flow | การเคลื่อนที่ปรากฏของแต่ละพิกเซลระหว่างเฟรม (เวกเตอร์ u, v) |
| Hexal / hex lattice | "พิกเซล" ของตาแมลงหวี่ ซึ่งเรียงตัวเป็นตาข่ายหกเหลี่ยม (721 จุดในโปรเจกต์นี้) |
| Cell type | ชนิดเซลล์ประสาท เช่น T4a, Mi1, L1 (flyvis มี 65 ชนิด) |
| Degree-preserving rewiring | สลับปลายทางของเส้นการเชื่อมต่อ โดยแต่ละโหนดยังมีจำนวนเส้นเข้า/ออกเท่าเดิม |
| Dale's law | เซลล์หนึ่งชนิดปล่อยสารสื่อประสาทแบบเดียว จึงกระตุ้นอย่างเดียวหรือยับยั้งอย่างเดียว |
| ConvGRU | GRU ที่ใช้ convolution แทน fully connected จึงจำข้อมูลข้ามเวลาและรักษาโครงสร้างเชิงพื้นที่ไว้ได้ |
| EPE | End-Point Error ระยะ Euclidean ระหว่างเวกเตอร์ flow ที่ทำนายกับค่าจริง |
| Pre-registration | เขียนสมมติฐานและวิธีวิเคราะห์ไว้ก่อนทดลอง เพื่อไม่ให้ปรับเรื่องเล่าตามผลที่ออกมา |
